# Обработка заявок

Десктопное приложение: загружает скан заявки на ремонтные работы (PDF),
распознаёт поля, даёт их поправить, подобрать материалы по виду работ
и формирует «Отчёт о выполненной работе» (.doc) по шаблону.

## Требования

- Windows 10/11 с русским языковым пакетом (встроенный OCR Windows)
- Microsoft Word (формирование отчёта через Word, проверено на Word 2007)
- Python 3.12+

```
pip install -r requirements.txt
```

## Шаблоны

Положите в папку `шаблоны/` рядом с программой (в git не хранится):

- `отчет_о_работе.doc` — пустая форма отчёта; текст вставляется после «использованы материалы:»
- `материалы(установка).xlsx`, `материалы(переустановка).xlsx`, `материалы(ремонт).xlsx` —
  стандартные перечни материалов по видам работ (форма «Приложение к отчёту»).
  Если файла нет, перечень для этого вида работ пустой, материалы добавляются вручную.

## Запуск

`Запуск.bat` или `python app.py`.

## Структура

- `app.py` — окно программы (tkinter)
- `request_parser.py` — разбор полей заявки
- `ocr.py` — рендер PDF, очистка рамок, распознавание текста
- `materials.py` — перечни материалов из Excel
- `report.py` — формирование отчёта через Word
- `данные/` — сохранённые данные заявок (JSON, не в git)
